# 커피 픽 (Coffee Pick)

브랜드 · 디카페인/스무디 여부 · 가격 조건에 맞춰 오늘의 커피 메뉴를 랜덤으로 뽑아주는 모바일 웹 서비스입니다.

디자인 소스: `GachaMain.dc.html` 프로토타입 아트보드 (발랄한 뽑기/가챠 감성, 3탭 구조). 구현 기준은 핸드오프 스펙 문서(색상 토큰, 상태/로직, 엣지 케이스)를 따릅니다.

## 화면 구성

하단 탭 내비게이션(탐색 / 뽑기 / 설정) + 오버레이 2종으로 구성됩니다. SPA 내부 상태(`screen`)로 전환되며 라우팅은 없습니다:

- **뽑기 (Draw)**: 브랜드 단일 선택(`<select>`) + 고급 필터(음료 종류·가격 상한) 후 랜덤 추첨
- **탐색 (Explore)**: 전체 메뉴 검색 + 음료 종류 필터, 목록형/그리드형 보기 전환
- **설정 (Settings)**: 다크 모드 토글, 앱 정보
- **뽑기 결과 (Result)**: 추첨된 메뉴 또는 "결과 없음" 안내 (풀스크린 오버레이, 내비 바 없음)
- **고급 필터 / 메뉴 필터 (바텀시트)**: 각각 뽑기 풀 / 탐색 목록에만 반영되는 독립된 필터 상태

다크 모드는 설정 탭에서 즉시 전환되며, 내비 바·브랜드·포인트 컬러 등 고정 컬러를 제외한 배경/텍스트/카드 색상이 함께 바뀝니다.

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm run build     # 타입체크 + 프로덕션 빌드
npm run lint      # oxlint
npm run preview   # 빌드 결과 미리보기
```

기준 프레임은 모바일 390×844px이며, 600px 이상 뷰포트에서는 폰 프레임 카드를 화면 중앙에 배치합니다.

## 참고

메뉴/브랜드 데이터는 현재 클라이언트에 하드코딩되어 있습니다(`src/data/menu.ts`). 실제 메뉴 연동, "이 메뉴로 결정!" 동작 확정, 다크 모드 선호도 영속화, 뽑기용 고급 필터와 탐색용 메뉴 필터의 상태 통합 여부 등은 핸드오프 스펙의 Open Questions 항목으로 남아 있어 이후 논의가 필요합니다.
