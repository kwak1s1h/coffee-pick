# 커피 픽 (Coffee Pick)

브랜드 · 디카페인/스무디 여부 · 가격 조건에 맞춰 오늘의 커피 메뉴를 랜덤으로 뽑아주는 모바일 웹 서비스입니다.

디자인 소스: `GachaMain.dc.html` 프로토타입 아트보드 (발랄한 뽑기/가챠 감성). 구현 기준은 핸드오프 스펙 문서(색상 토큰, 상태/로직, 엣지 케이스)를 따릅니다.

## 화면 구성

SPA 내부 상태(`screen`)로 전환되는 4개 화면입니다 (라우팅 없음):

- **뽑기 (Main)**: 현재 필터 요약 확인 + 랜덤 추첨
- **필터 (Filter)**: 음료 종류 / 가격 상한 단일 선택
- **브랜드 (Brand)**: 카페 브랜드 다중 토글
- **결과 (Result)**: 추첨된 메뉴 또는 "결과 없음" 안내

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm run build     # 타입체크 + 프로덕션 빌드
npm run lint      # oxlint
npm run preview   # 빌드 결과 미리보기
```

기준 프레임은 모바일 390×844px이며, 600px 이상 뷰포트에서는 폰 프레임 카드를 화면 중앙에 배치합니다.

## 참고

메뉴/브랜드 데이터는 현재 클라이언트에 하드코딩되어 있습니다(`src/data/menu.ts`). 실제 메뉴 연동, "이 메뉴로 결정!" 동작 확정, 필터/브랜드 상태 영속화 등은 핸드오프 스펙의 Open Questions 항목으로 남아 있어 이후 논의가 필요합니다.
